# DZlog Design System v1.0 Usage Rules

- UI colors must come from `DDZColor` (avoid `Color(0x...)` literals in screens/components).
- Typography must use `DDZTypography` (avoid hardcoded `fontSize`/`fontWeight` in screens).
- Spacing must use `DDZSpacing` (avoid hardcoded padding/Spacer sizes in screens).
- Prefer `DDZCard`, `DDZButton`, and `DDZSectionHeader` for standard card/button/section patterns.
