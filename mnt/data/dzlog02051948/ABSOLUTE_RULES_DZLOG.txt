DZlog 절대규칙 (수정/확장 시 기준)

1) 파일 경로 그룹(G1/G2) 의미
- G1: 상위 폴더(저장경로 1단계)
- G2: 하위 폴더(저장경로 2단계)

2) 파일 경로 그룹 선택 UX 규칙
- 선택 상태는 3가지: 없음 / G1 / G2
- 아무도 G1이 아닌 상태에서는 G1만 선택 가능하며, G2는 비활성화됨
- G1이 존재하면 다른 셀에서 G2 선택이 가능함
- G1로 지정된 셀 본인에서는 G2 선택 불가(비활성)
- G1을 다른 셀로 지정하면 기존 G1은 해제(없음)됨
- G2를 다른 셀로 지정하면 기존 G2는 해제(없음)됨
- G2 셀에서 G1을 선택하면 "G2→G1 승격"으로 동작하며, 기존 G1은 해제되고 G2는 사라짐(=해당 셀이 G1이 됨)
