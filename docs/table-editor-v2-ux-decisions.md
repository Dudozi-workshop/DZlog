# Table Editor V2 UX Decisions

기준 브랜치: `feat/table-editor-v2-ux-mock`

이 문서는 표 상세설정 V2의 UI/UX 논의 중 확정된 사항을 고정한다.
저장 규칙의 내부 정책/카운터 스코프 계산은 별도 논의 범위이며, 여기서는 UI 책임만 정의한다.

## 1. 전체 편집 원칙

- 표에서는 직접 선택하고 수정한다.
- 표 구조 변경은 `레이아웃`에서 한다.
- 보이는 방식 변경은 `스타일`에서 한다.
- 저장 방식 변경은 `저장 규칙`에서 한다.
- 별도의 `내용` 탭은 두지 않는다.
- 내부 구현 용어인 `slot`, `G1/G2` 등은 사용자 UI에 노출하지 않는다.
- 기본 화면은 설명보다 실제 표 미리보기가 중심이 되도록 한다.

## 2. 메인 편집 화면

상단:
- 뒤로
- 제목: `표 편집`
- Undo
- Redo
- 저장

중앙:
- 실제 표 미리보기를 화면의 주영역으로 사용
- 안내 문구는 `수정할 셀을 눌러보세요` 수준의 짧은 힌트만 허용
- 별도의 설명 카드/온보딩 카드는 기본 상태에서 노출하지 않음

하단 고정 액션 3개:
1. 레이아웃
2. 스타일
3. 저장 규칙

세 버튼은 동일 계층으로 표현한다.

## 3. 셀 선택/편집

셀 탭 시 작은 하단 패널을 연다.
기본 패널은 최대 3~4줄 수준으로 유지한다.

공통:
- 현재 값 또는 미리보기
- `셀 종류  현재 타입 >`
- 타입별 필수 설정만 추가

셀 타입은 평소 한 줄로만 표시하고, `셀 종류`를 누르면 Bottom Sheet에서 전체 타입을 버튼형으로 보여준다.

타입:
- 텍스트
- 숫자
- 자동번호 (내부 COUNTER)
- 날짜
- 시간
- 순환문구

타입별 기본 노출:
- 텍스트: 값 입력
- 숫자: 값 입력
- 자동번호: 현재/다음 번호, 동기화 관련 최소 정보
- 날짜: 현재 날짜 미리보기, 날짜 형식
- 시간: 현재 시간 미리보기, 시간 형식
- 순환문구: 현재 문구 미리보기, 연결 문구 세트

기본 셀 편집에서 제외:
- 정렬
- 글자 크기
- 글자색
- 배경
- 파일명
- 저장경로
- 카운터 스코프

셀 편집의 책임은 `내용/타입`에 한정한다.

## 4. 레이아웃

레이아웃은 표 내부 구조만 편집한다.
표 전체의 화면상 위치/전체 크기는 여기서 다루지 않는다.

레이아웃 모드:
- 셀/범위 선택
- 행 추가
- 열 추가
- 병합
- 병합 해제
- 행 삭제
- 열 삭제
- 행 높이 조절
- 열 너비 조절

기본 동작:
- 선택된 행 기준 아래에 행 추가
- 선택된 열 기준 오른쪽에 열 추가
- 선택이 없으면 맨 아래/맨 오른쪽에 추가
- 병합은 직사각형 범위에만 허용
- 삭제는 즉시 구조를 지우지 않고 삭제 종류를 확인하는 UI를 거침
- 셀 내용 삭제는 레이아웃 삭제와 분리

크기 조절:
- 행/열 경계 직접 드래그 우선
- 드래그 터치 영역은 실제 선보다 넓게 확보
- 드래그 중 수치 또는 시각 피드백 제공
- 별도 슬라이더는 기본 노출하지 않음

범위 선택:
- 첫 셀 선택 후 두 번째 셀 선택 시 두 셀 사이 직사각형 범위 자동 선택을 우선 후보로 사용

표 전체 위치/전체 크기:
- 카메라/실제 촬영 Preview에서 화면 비율을 보면서 조정
- 레이아웃 편집에서는 제외

## 5. 스타일

스타일은 우선 전체 표 기준으로 적용한다.

기본 노출:
- 배경: 밝게 / 어둡게 / 투명
- 글자 크기
- 정렬: 왼쪽 / 가운데 / 오른쪽
- 테두리 ON/OFF

세부 옵션은 `더보기`로 접는다.

후순위/고급:
- 글자색
- 테두리 두께
- 투명도
- 기타 세부 표현

현재 단계에서는 셀별 개별 스타일을 기본 기능으로 노출하지 않는다.

## 6. 저장 규칙 UI 경계

메인 화면에는 `저장 규칙` 진입점만 둔다.
저장 규칙의 내부 정책은 별도 논의에서 확정한다.

현재 UI 방향:
- 파일명 요약
- 저장경로 요약
- 자동번호 요약
- 고급 설정

저장경로 UI는 최대 3단계 표현을 허용하는 방향으로 잡되,
구체 저장 규칙/스코프 정책은 별도 채팅에서 결정한다.

## 7. 현재 UX 상태

1차 확정 후보:
- 메인 편집 화면
- 하단 3액션
- 셀 타입 선택 방식
- 셀/스타일/저장 규칙의 책임 분리
- 레이아웃 구조 편집 범위
- 스타일 기본 범위

다음 UI 논의 시 이미 확정된 위 항목을 반복 논의하지 않고,
미확정 세부 동작/화면만 이어서 결정한다.
