# iOS M3-A 병합 표·카메라·갤러리 검증 체크포인트

PR: https://github.com/Dudozi-workshop/DZlog/pull/87 — Draft·미병합 유지

이 문서는 이전 체크포인트다. 실시간 표 조작과 썸네일 수정을 포함한 최신 전체 UI 27개 통과 결과·실기기 QA는 [최신 통합 검증 보고서](ios-m3a-live-table-checkpoint-20261104.md)를 기준으로 한다.

검증 대상 코드: `a3be0dbc1472e7808b741a6cc5241476e0faf01e`.

요청한 저장 모드·표 배치 연결 및 PhotoKit 저장·복구·읽기 갤러리 확장의 자동 검증을 완료했다. 다음 확인 단계는 실제 iPhone 설치·검수다.

## 구현

- 유효한 병합 표에서 ORIGINAL_ONLY / WATERMARK_ONLY / BOTH 저장을 연결했다. 병합 내부 경계선을 제거하고 행·열 가중치를 반영하며, 가려진 셀 데이터는 보존한다. 잘못된 범위·겹침·중복·누락은 저장 전에 차단한다.
- 카메라에서 촬영 설정을 저장하고 복귀하면 저장 모드·표 배치·다음 번호를 같은 iOS 워크스페이스에 반영한다. 파일명에서 저장 정보와 논리 경로를 확인한다.
- 기기 지원 여부에 따라 자동초점·줌·플래시를 제어한다. 설정·갤러리 왕복 시 촬영 세션을 중지하고 다시 시작하며, 저장 중·복구 대기 상태의 제어 제한을 유지한다.
- 읽기 갤러리에 폴더 탐색, 그리드/목록, 로컬 썸네일, 확대 보기, 이전/다음, 같은 촬영의 원본/결과 전환을 연결했다. 접근 불가·누락으로 바뀐 썸네일 상태와 캐시를 지운다.
- EXIF 방향이 있는 사진은 표시·합성용 래스터만 정규화한다. 원본 입력 바이트는 변경하지 않고 PhotoKit에 전달한다. Photos가 보관한 실제 센서 파일의 EXIF·해상도 보존은 실기기 QA에 남긴다.
- 이번 변경은 iOS 어댑터·iOS UI·검증 코드에 한정했다. Android 및 common 프로덕션 소스와 기존 Android 사용자 데이터는 변경하지 않았다.

시뮬레이터 테스트는 센서 JPEG만 합성 입력으로 사용한다. 저장·재조회·재실행 복구·갤러리는 실제 PhotoKit을 사용한다. 실제 iPhone 센서 촬영이나 Android/iOS 시각 동등성을 인증한 결과가 아니다.

로컬 환경이 사용 가능할 때 `git diff --check`와 `bash -n scripts/ios/test-ui-poc.sh`를 통과했다. Apple SDK 컴파일과 XCTest는 macOS CI에서 수행한다.

## 수정 및 실행 이력

- `49e33b5`: 병합 렌더링 및 픽셀·비정상 span 검증. 픽셀 테스트와 코어·Android·ARM64는 통과했다. media UI 13개 중 7개는 늦게 나타난 권한 창을 다음 테스트에서 XCTest 기본 핸들러가 거부한 뒤 연쇄 실패했다.
- 권한 창 공통 인터럽션 처리와 저장 완료/권한 창 동시 대기를 추가했다. Photos 권한을 우회하거나 가짜 저장소로 바꾸지 않았다.
- `77594f0`: 카메라·갤러리·방향 처리. 공유 코어 86개 통과. AVFoundation 확장 API import·매개변수 이름·UIImage 방향 enum 참조 오류는 `60626b9`에서 수정했다.
- `60626b9`: 관련 UI 8개 통과 후 전체 검증으로 대체해 취소했다. 17개 media 전체 성공으로 계산하지 않는다.
- `975bc2a`: 전체 UI 17개 통과 후 썸네일 접근 상태 수정으로 대체해 취소했다. 세 저장 모드/복구, 카메라 설정 왕복, 기존 편집기/홈 일부, EXIF, 갤러리 전환이 통과했지만 전체 25개 성공으로 계산하지 않는다.
- `a3be0db`: 접근 불가/누락 시 기존 `produceState` 값과 썸네일 캐시를 명시적으로 지운다. 이 코드로 최종 전체 검증한다.

## 남은 작업

- 실시간 표 오버레이 이동·크기 조절은 후속 `7f46c78`에서 구현·전체 UI 검증 완료. 빠른 필드 편집 등 Android 카메라 전체 기능 동등성은 미완료.
- 갤러리 삭제·이동·공유·즐겨찾기. 현재 갤러리는 읽기 전용이며 폴더는 DZlog 인덱스의 논리 경로다.
- Android/iOS 동일 사진·표 fixture의 시각 비교와 실제 iPhone QA.
- 설치용 서명·프로비저닝 및 실기기 설치. ARM64 unsigned 호스트는 설치 가능한 서명 IPA가 아니다. 확인된 개발 Team ID가 없어 설치 경로와 서명 팀 확인이 필요하다.

이번 체크포인트는 저장 흐름과 갤러리 확장 범위를 다룬다. M3-A 전체 UI/UX 동등성이나 출시·병합 완료를 선언하지 않는다.

1. 카메라 권한 최초 허용/거부, 설정에서 변경 후 복귀, 카메라 사용 불가 시 제어 비활성화.
2. 세 저장 모드의 1/1/2개 저장, 파일명·논리 경로, 다음 번호가 정확히 한 번 증가하는지 확인.
3. 수평·수직 병합, 가중치, 한글·폰트·테두리·색상, 모든 배치 앵커/사용자 위치/90도 회전.
4. 센서 사진 방향, 미리보기 crop과 결과 사진 배치, Photos의 원본 EXIF·해상도 보존.
5. 자동초점·줌 범위·플래시 꺼짐/자동/켜짐, 설정·갤러리 왕복 후 세션 재시작.
6. 저장 중 중단·재실행, PhotoKit 성공 뒤 워크스페이스 실패, 반복 복구 시 번호 중복 증가·사진 중복 생성 여부.
7. 제한된 사진 접근·접근 취소·Photos 외부 삭제·iCloud 사진, 새로고침 후 접근 불가 이미지 제거, 대용량 스크롤·메모리.
8. 폴더/전체, 그리드/목록, 확대, 이전/다음, 원본/결과 전환, 연속 촬영 후 최신 결과 선택.
