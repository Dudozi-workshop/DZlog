## 1. 휴대폰에서 테스트 준비

1. 위 **검수용 APK ZIP** 링크 열기 → GitHub Actions의 아티팩트 ZIP 다운로드 → 압축 해제 → `app-debug.apk` 설치. 설치 허용 여부는 Android 기기의 출처별 '알 수 없는 앱 설치' 설정에 따름.
2. 홈 화면에 별도의 **DZlog QA pr117** 앱이 설치되는지 확인. 기존 앱은 제거하거나 덮어쓰지 않기.
3. QA 앱에서 테스트용 **6×6 표**(텍스트·숫자·날짜·시간·순환문구 포함)를 만들고, 긴 표 스크롤 검수를 위해 행을 늘려 **20행** 정도의 표도 준비.
4. **순환문구 세트 A/B/C**를 만들고 전체 기본 주기를 **5장**으로 설정. 같은 세트를 사용하는 셀 2개를 준비.
5. 테스트 결과는 아래 체크박스 및 실패 기록란에 기재. **미실행은 통과로 처리하지 않음.**

> 설치가 되지 않으면 ZIP 파일을 APK로 착각해 설치하지 않았는지, 압축 해제 후 APK인지, 설치 권한이 허용되어 있는지 확인. CI 아티팩트는 정식 배포 APK가 아님.

## 5. 판정 기준

- **자동 테스트 PASS ≠ 실기기 QA PASS.** PR #117은 이미 integration에 병합됐지만, 실기기 검수는 아직 끝나지 않았다.
- 필수 12건을 모두 실행하고 실패가 없을 때 이 체크리스트를 실기기 PASS로 갱신한다. 핵심 항목 하나라도 실패하면 해당 이슈를 수정·재검증한 후 다시 판정한다.
- 테스트용 QA APK 설치 자체가 정식 Play Store 업데이트를 의미하지 않는다. 정식 배포는 별도 승인·릴리스 검증을 거쳐 진행한다.
