# Counter Scope 4조합 회귀 고정표

이 문서는 카운터 scope 동작을 4조합(Path/Filename ON/OFF) 기준으로 고정 검증하기 위한 회귀 표입니다.

## 판정 원칙(고정)
- Path ON: 저장경로 변경에 반응(새 스트림)
- Path OFF: 저장경로 변경에 미반응(같은 스트림)
- Filename ON: 파일명 prefix 변경에 반응(새 스트림)
- Filename OFF: 파일명 prefix 변경에 미반응(같은 스트림)
- Path OFF + Filename OFF: **완전 전역 스트림**으로 동작(전체 최대값 + 1)

## 4조합 기대결과 매트릭스

- Path ON / Filename ON
  - 저장경로 변경: 반응
  - 파일명 변경: 반응
  - 기대: 둘 중 하나라도 바뀌면 새 스트림
- Path ON / Filename OFF
  - 저장경로 변경: 반응
  - 파일명 변경: 미반응
  - 기대: 경로가 바뀔 때만 새 스트림
- Path OFF / Filename ON
  - 저장경로 변경: 미반응
  - 파일명 변경: 반응
  - 기대: 파일명이 바뀔 때만 새 스트림
- Path OFF / Filename OFF
  - 저장경로 변경: 미반응
  - 파일명 변경: 미반응
  - 기대: 경로/파일명 바뀌어도 같은 스트림

## 에뮬 고정 시나리오
1. 기준값 설정: 경로=`A/B`, 파일명 prefix=`C`
2. 각 모드에서 3회 촬영해 기준 next 확보
3. 경로만 변경(`A/B -> A/D`) 후 2회 촬영
4. prefix만 변경(`C -> E`) 후 2회 촬영
5. 표의 기대결과와 실제를 PASS/FAIL로 기록

## PASS 조건
- 기대결과 매트릭스와 100% 일치
- 같은 스트림으로 판정된 구간에서는 카운터 역행/초기화 없음
- 새 스트림으로 판정된 구간에서는 해당 스트림 기준 next로 정상 전환
