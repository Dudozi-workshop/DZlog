# M2-C1 기존 템플릿 목록 재사용

기준 #75 5d4748cb. 홈은 ViewModel·사진·설정·저장 경로와 연결되어 있어 다음 패치로 분리한다.
이번 패치는 기존 목록 표시·미리보기·선택과 돌아가기를 먼저 공통화한다.

- 기존 TableTemplateListScreen 본문을 sharedUi TableTemplateListContent로 이동한다.
  Android 기존 진입점/콜백과 SimpleDateFormat 날짜 표시는 유지한다.
- 버튼/카드/상단바/dialog/layout 정의는 원문 그대로 이동한다. 기존 Android 호출부도
  같은 구현을 사용한다. miniature Canvas는 동일 가중치와 기존 shared root 규칙을 재사용한다.
- 정렬·선택·미리보기·이름 변경·복제·삭제 확인 UI는 기존 코드 유지.
  실제 생성/수정/저장/삭제는 호출부 책임이며 저장소·사진·DB·설정은 변경하지 않는다.
- iOS 메모리 전용 PoC는 기존 목록을 열고 미리보기→선택→현재 선택 표시→뒤로가기를 연결한다.
  영속 저장/편집 연결은 아직 없어 관리 버튼을 숨긴다. Android는 관리 표시 기본값을 유지한다.
  iOS 홈을 구현했다고 취급하지 않는다. PoC 진입 화면은 정식 홈 디자인이 아니다.
- 미리보기 썸네일에 의미 있는 접근성 이름을 부여한다. 기존 AX/VoiceOver 문제의
  해결을 의미하지 않는다. 기존 실제 조작3개는 유지하고 목록 탐색1개를 추가한다.

검증: 이동5개 파일 원문 동일·diff check 확인. Android/core/UI CI 최종 결과는 PR과
기존 Notion 문서에 기록한다. 실기기/전체 화면/디자인 승인/140%·다기기/영속 저장은 미검증.
