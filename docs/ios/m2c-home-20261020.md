# M2-C2 기존 홈 UI 재사용

기준 #76 02e186d5. 새 PR 없이 같은 브랜치에 이어서 구현한다.

- HomeScreen 표시 본문을 HomeContent로 이동한다. Android lifecycle/ViewModel/MediaStore·Coil,
  기존 다음 번호 계산·문자열 리소스·내비게이션 콜백·저장 정보 창과 refresh 순서는 유지한다.
- HomeRecentCaptureContent는 기존 사진/빈 상태 배치를 재사용하고 이미지 로딩만 슬롯으로 받는다.
  AlbumViewAction/IconButton·3구역 layout·그림자 mask를 이동하며 HomeUiSpec 값은 유지한다.
- HomeAmbientContent는 기존 배경·잎 그림자의 위치·크기·mask·애니메이션을 재사용한다.
  Android는 기존 R.drawable을 계속 로드하고 iOS는 같은 PNG blob을 번들에서 로드한다.
  새 디자인/이미지 생성은 없다. Xcode와 수동 Swift build 모두 기존 PNG를 포함한다.
- iOS 메모리 전용 host에서 기존 홈→목록→미리보기→선택→홈/다시 목록→뒤로가기를 연결한다.
  실제 사진 조회·카메라·편집·저장/설정/앨범은 아직 연결하지 않아 해당 버튼을 비활성화한다.
  Android의 활성 기본값/콜백은 그대로다. iOS 수치는 합성 표시이며 실제 촬영 계산 검증이 아니다.
- 기존 목록 검사1개를 홈 경유로 확장하고 기존 미리보기/가로·세로3개를 유지한다.
  첫 홈/빈 최근 사진 상태와 목록 screenshot을 xcresult에 남긴다.
