# DZlog iOS M3-A — 빠른 수정 자동 셀·템플릿 전환

기준일: 2026-11-11 KST. PR #87은 Draft·미병합 유지한다.

## 구현 범위

- Android의 빠른 수정 셀 선별, 날짜 형식, 순환문구 세트 선택 정책을 KMP 공통 코어로 이동했다. Android 동작 규칙과 저장 형식은 바꾸지 않는다.
- iOS 빠른 입력에서 텍스트·숫자뿐 아니라 날짜 형식, 촬영 시각 안내, 순환문구 세트 선택을 제공한다.
- 순환문구 세트를 바꾸면 해당 셀만 첫 문구·첫 촬영 상태로 초기화하고, 같은 세트를 다시 선택하면 진행 상태를 보존한다.
- 빠른 수정 안에서 다른 템플릿으로 전환할 수 있다. 전환 전에 현재 초안을 저장하고, 대상 템플릿의 값·번호·배치·저장 설정은 독립적으로 불러온다.
- 취소는 초안을 저장하지 않으며 완료 또는 템플릿 전환 때만 워크스페이스를 기록한다. 오래된 화면, 외부 워크스페이스 변경, 복구 대기 상태의 쓰기는 계속 차단한다.

## 검증 범위

- 공통 코어: 잠긴 셀·카운터 제외, 날짜 허용 형식, 순환문구 변경 시 진행 초기화 및 잘못된 세트 거부.
- iOS 정책 fixture: 수동값과 자동값을 함께 적용하고 번호·배치 메타데이터 보존, 잘못된 날짜/세트와 오래된 워크스페이스 차단.
- iOS UI: 날짜·순환문구 선택 후 저장·촬영·재실행 보존, 현재 초안 저장 후 템플릿 전환, 활성 템플릿·독립 번호·초안 재복원.
- 기존 빠른 수정 집중 묶음은 4개 테스트, 전체 UI 묶음은 30개 테스트가 된다.

## 현재 게이트

- 로컬 공백 검사와 iOS 테스트 선택 스크립트 문법 검사는 수행한다.
- 이 작업환경에는 Gradle 8.13 배포본과 Apple SDK가 없어 JVM/Kotlin Native/XCTest 결과는 GitHub Actions에서 확인한다.
- 집중 자동 검증과 전체 30개 통합 검증이 모두 성공하기 전에는 완료·병합·배포로 간주하지 않는다.
