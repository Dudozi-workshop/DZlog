DZlog 절대규칙 (변경 시 기준)

1) 작업 절차
- 변경은 1회에 1개 이슈 단위로 쪼개서 진행한다.
- 각 단계는 컴파일/실행이 가능한 상태를 유지한다.
- 패치는 항상 (1) 변경요약, (2) git diff(클립보드용), (3) 에뮬 체크리스트 3종 세트로 제공한다.
- 추론으로 결정하지 않는다. 애매하면 질문하고, 결정 후 반영한다.

2) 카운터 정책
- 카운터 스트림 키 = relativePath + counterPrefix
- counterPrefix는 "파일명 포함 셀" 기반 prefix이며, 날짜/시간은 스트림에 포함하지 않는다.
- next counter = 해당 스트림에서 사용된 최대값 + 1

3) 저장경로(G1/G2) 정책
- G1/G2는 파일 저장 경로 구성 요소다. G1=상위, G2=하위다.
- 저장경로가 비어있으면, 저장경로 지정의 첫 선택은 G1로만 가능하다(G2는 비활성).
- G1이 존재하면, 다른 셀에서 저장경로를 지정할 때 기본은 G2가 된다(기존 G2가 있으면 교체).
- G1로 지정된 셀 본인에서는 G2 선택을 비활성으로 둔다.
- G2로 지정된 셀에서 G1을 선택하면, 해당 셀이 G1이 되고 기존 G1은 해제된다. 이때 G2는 비어있는 상태로 남는다(필요하면 다른 셀에서 다시 G2 지정).
